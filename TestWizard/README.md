# TestWizard

Sample WinForms application that ships with David Hall's AeroWizard library.

It is the second project in `AeroWizard.sln`. On startup (`Main_Load`) it shows `MyWizard` as a dialog, then closes. `MyStepWizard` is an additional wizard form in the same project.
